# NOVA সার্ভার — শুধু ব্রাউজারে, Termux ছাড়া

**Termux লাগবে না। কমান্ড লিখতে হবে না।** ফোনের ব্রাউজারে ট্যাপ করে
করে হয়ে যাবে। সময় ১০ মিনিট, খরচ শূন্য।

যা পাবে:

- অ্যাপে কোনো API key থাকবে না — key থাকবে সার্ভারে
- টিমের প্রত্যেকে পাবে একটা ছোট কোড, যেমন `salman`
- কোটা শেষ হলে **১ ঘণ্টা পর নিজেই সচল**
- **মোটে ২টা key দিয়েই শুরু করা যায়** (Groq একটা, AI Studio একটা)

---

## ধাপ ১ — অ্যাকাউন্ট

ব্রাউজারে যাও: **dash.cloudflare.com**

Sign up → ইমেইল আর পাসওয়ার্ড → ইমেইলে আসা লিংকে ট্যাপ করে verify।
কার্ড লাগবে না।

## ধাপ ২ — Worker বানাও

সাইডবারে **Compute (Workers)** → **Create** বাটন
→ **Start with Hello World!** এর নিচে **Get started**
→ নাম দাও `nova`
→ **Deploy**

দশ সেকেন্ড, হয়ে গেল।

## ধাপ ৩ — কোড বসাও

Worker-এর পাতায় **Edit code** (বা `< >` আইকন) ট্যাপ করো।
একটা এডিটর খুলবে, ভেতরে নমুনা কোড থাকবে।

**সব লেখা মুছে ফেলো**, তারপর এই জিপের ভেতরের **`server/worker.js`**
ফাইলটার পুরো লেখা কপি করে ওখানে পেস্ট করো।

> ফোনে ফাইলটা খুলবে কীভাবে: Files অ্যাপে `worker.js` চেপে ধরো
> → Open with → যেকোনো টেক্সট এডিটর। সব সিলেক্ট করে কপি।

উপরে ডানে **Deploy** ট্যাপ করো।

## ধাপ ৪ — key আর কোড বসাও

Worker-এর পাতায় ফিরে যাও → **Settings** → **Variables and Secrets**
→ **Add**।

প্রতিটার জন্য **Type = Secret** রাখবে (Text নয়)। দুটো অবশ্যই লাগবে:

| Name | Value |
|---|---|
| `GROQ_KEY` | তোমার Groq key (`gsk_...`) |
| `CODES` | টিমের কোড কমা দিয়ে — `salman,rakib,tanvir` |

ব্যাকআপের জন্য AI Studio-র key-টাও দাও:

| Name | Value |
|---|---|
| `GEMINI_KEY` | `AIza...` |

শেষে **Deploy** ট্যাপ করো, নইলে key কাজে লাগবে না।

## ধাপ ৫ — দেখে নাও

Worker-এর ঠিকানাটা ব্রাউজারে খোলো:

```
https://nova.তোমার-নাম.workers.dev
```

একটা বাংলা পাতা দেখাবে। সবুজ **"✓ সব ঠিক আছে"** এলে সার্ভার তৈরি।
লাল কিছু থাকলে পাতাটাই বলে দেবে কী বাকি।

## ধাপ ৬ — অ্যাপে জুড়ে দাও

সেটিংস →

| ঘর | কী দেবে |
|---|---|
| প্রোভাইডার | `NOVA সার্ভার (কোড দিয়ে)` |
| সার্ভারের ঠিকানা | উপরের URL |
| অ্যাকসেস কোড | `salman` |
| মডেল | **ফাঁকা রাখো** |

Save → মেসেজ পাঠাও। শেষ।

## ৬টা key বসানো — দুটো ঘরেই

**নতুন ভেরিয়েবল বানাতে হবে না।** যে দুটো আছে, সেগুলোতেই কমা দিয়ে সব key
একসাথে লিখে দাও।

Cloudflare → `nova` → **Settings** → **Variables and Secrets** →
`GROQ_KEY` এর পাশে **Edit** (পেন্সিল) → পুরো ঘরটা এভাবে লেখো:

```
gsk_প্রথমটা,gsk_দ্বিতীয়টা,gsk_তৃতীয়টা
```

কমার আগে-পরে ফাঁকা জায়গা দিলেও সমস্যা নেই।

তারপর **+ Add variable** → `GEMINI_KEY` (Type = Secret):

```
AIza_প্রথমটা,AIza_দ্বিতীয়টা,AIza_তৃতীয়টা
```

**Deploy** চাপো। ঠিকানাটা খুলে দেখো:

```json
"keys":{"groq":3,"gemini":3}
```

## key কীভাবে ঘোরে

তোমার নিয়মেই চলে — **লাফিয়ে যায় না, ফিরে আসে**:

১. সবসময় **১ নম্বর** key দিয়েই কাজ হয়
২. ১ এর কোটা শেষ → সে **বিশ্রামে** যায় (যতক্ষণ প্রোভাইডার বলেছে ততক্ষণ),
   কাজ চলে **২** দিয়ে
৩. ২ চলার সময় **৩ ছোঁয়া হয় না**
৪. ২ ও শেষ হলে তবেই **৩**
৫. **১ এর বিশ্রাম শেষ হলেই আবার ১ এ ফিরে আসে** — ৩ এ পড়ে থাকে না
৬. তিনটে Groq-ই বিশ্রামে গেলে **AI Studio** এর পালা, ওখানেও একই নিয়ম

সার্ভার প্রোভাইডারের এরর পড়ে বোঝে কতক্ষণ বিশ্রাম দরকার
("try again in 1h26m33s" → ৮৭ মিনিট)। বলা না থাকলে ১ ঘণ্টা ধরে নেয়।

> ⚠️ **এর জন্য KV লাগবে** — নিচের "ঘণ্টার হিসাব" অংশটা করতেই হবে,
> নইলে সার্ভার মনে রাখতে পারবে না কে বিশ্রামে আছে।

ঠিকানাটা খুললে দেখতে পাবে কোনটা চলছে, কোনটা বিশ্রামে, আর কত মিনিট বাকি।

## কয়টা key লাগবে?

**দুটোই যথেষ্ট।** Groq একটা, AI Studio একটা। হিসাব করে দেখো:

| | দিনে |
|---|---|
| Groq × ৩ | ~৩,০০০ |
| AI Studio × ৩ | ~৪৩,২০০ |
| **মোট** | **~৪৬,০০০** |

৫ জনের টিমে জনপ্রতি ৩,০০০। কেউ দিনে ৩,০০০ মেসেজ পাঠায় না।

**নতুন key জোগাড় করার দরকার নেই।** পরে যদি কখনো লাগে, একই
সিক্রেটে কমা দিয়ে জুড়ে দিও:

```
GROQ_KEY = gsk_এক,gsk_দুই
```

সার্ভার নিজেই লাইন ধরে এগোবে — প্রথমটা শেষ হলে দ্বিতীয়টা,
সব Groq শেষ হলে Gemini।

## ঐচ্ছিক — ঘণ্টার হিসাব

এটা **না করলেও অ্যাপ চলবে**। কোড ছাড়া কেউ ঢুকতে পারে না, তাই
হিসাব না রাখলেও ক্ষতি নেই।

চাইলে: Worker → **Settings** → **Bindings** → **Add** → **KV namespace**
→ Variable name `NOVA_KV` → নতুন namespace বানাও → **Deploy**।

তখন প্রতি কোডে ঘণ্টায় ৪০টা মেসেজ। শেষ হলে অ্যাপ বলবে
"আর ২৩ মিনিট পর আবার চালু হবে" — তারপর আপনাআপনি ফিরে আসে।

সংখ্যাটা বদলাতে `HOURLY_LIMIT` নামে আরেকটা Secret দাও, মান `100`।

## চালানোর সময়

**কাউকে বাদ দিতে।** Settings → Variables → `CODES` এডিট করে তার নাম
মুছে দাও → Deploy। সাথে সাথেই বন্ধ। APK আপডেট লাগবে না।

**নতুন সদস্য।** `CODES` এ নাম জুড়ে দাও → Deploy। তাকে ঠিকানা আর
কোডটা বলে দাও।

**ঠিকানা ফাঁস হলে?** ক্ষতি নেই — কোড ছাড়া সার্ভার 401 দেয়, key
কখনো বাইরে যায় না।

**তোমার আসল কোটা বাড়ে না।** সার্ভার ঐ key-গুলোই ব্যবহার করছে,
শুধু লুকিয়ে রাখছে আর ভাগটা নিয়ন্ত্রণ করছে।

```bash

```

`16 পাস, 0 ফেল` এলে ঠিক আছে। **এটা না চালালেও কিছু হবে না।**
