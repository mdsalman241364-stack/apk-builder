# অটো-আপডেট — APK ছাড়াই নতুন চেহারা

অ্যাপের পুরো ইন্টারফেস একটাই ফাইল: `assets/ui.html`। সেটা সার্ভারে
রাখলে অ্যাপ নিজেই টেনে নেয় — কাউকে নতুন APK দিতে হয় না।

**যা এভাবে বদলানো যায়:** চেহারা, রং, লেখা, বোতাম, সাজানো, নতুন স্ক্রিন।
**যা যায় না:** জাভা কোড (নতুন টুল, ক্যামেরা, ফাইল হ্যান্ডলিং) — ওগুলোয়
নতুন APK লাগবেই।

বাস্তবে বেশিরভাগ আপডেটই প্রথম দলের।

---

## একবারের সেটআপ

### ১. KV চালু করো

এটা ছাড়া হবে না — নতুন UI কোথাও তো রাখতে হবে।

**nova → Settings → Bindings → Add → KV namespace**

ড্রপডাউনে namespace না থাকলে আগে বানাও:
সাইডবার **☰ → Storage & Databases → KV → Create instance**, নাম `nova-kv`।

তারপর ফিরে এসে:

| ঘর | মান |
|---|---|
| Variable name | `NOVA_KV` |
| KV namespace | `nova-kv` |

**Add Binding** → **Deploy**

### ২. দুটো ভেরিয়েবল

**Settings → Variables and Secrets → + Add variable**

| Name | Value | Type |
|---|---|---|
| `ADMIN` | নিজের একটা গোপন শব্দ | Secret ☑ |
| `UI_VERSION` | `1` | Text |

`ADMIN` কাউকে দিও না — এটা দিয়েই সবার অ্যাপের চেহারা বদলানো যায়।

**Deploy**

## প্রতিবার আপডেট — ৩ ধাপ

### ব্রাউজার থেকে (Termux লাগে না)

**১.** ফোনে খোলো:

```
https://nova.mdsalman0177598.workers.dev/ui/upload
```

**২.** অ্যাডমিন কোড দাও, `ui.html` ফাইলটা বেছে দাও, **পাঠাও** চাপো

**৩.** Cloudflare → Settings → Variables → `UI_VERSION` এর সংখ্যাটা **১ বাড়াও** → **Deploy**

শেষ। সবার অ্যাপ পরেরবার খুললেই নতুন চেহারা।

### Termux থেকে

```bash
cd /sdcard/NOVA-AIDE/server
bash push.sh
```

কোড চাইবে, দিলেই পাঠিয়ে দেবে। তারপরও `UI_VERSION` বাড়াতে হবে।

## অ্যাপ কীভাবে বোঝে

চালু হওয়ার সময় অ্যাপ `/ui/version` এ জিজ্ঞেস করে। সংখ্যাটা আগেরবারের
চেয়ে বড় হলে নতুন `ui.html` নামিয়ে রাখে, আর **পরেরবার খোলার সময়**
সেটা দিয়েই চলে।

চলন্ত অবস্থায় স্ক্রিন বদলে যায় না — যেমন সব অ্যাপে হয়।

দিনে বড়জোর চারবার খোঁজ নেয় (৬ ঘণ্টায় একবার), তাই ডেটা খরচ নেই বললেই চলে।

**নেট না থাকলে, সার্ভার বন্ধ থাকলে, ফাইল অর্ধেক নামলে** — অ্যাপ চুপচাপ
আগেরটা দিয়েই চলে। কখনো সাদা স্ক্রিন আসবে না।

---

## ভুল হলে ফিরে যাওয়া

খারাপ UI পাঠিয়ে ফেললে: আগের ভালো `ui.html` টা আবার আপলোড করো,
`UI_VERSION` আরেকবার বাড়াও, Deploy।

একদম বাদ দিতে চাইলে `UI_VERSION` কে `0` করে দাও — অ্যাপ তখন APK-র
ভেতরের আসল ফাইলটাই ব্যবহার করবে।

## নিরাপত্তা

- **আপলোড করতে `ADMIN` লাগে** — অন্য কেউ পাঠাতে পারবে না
- অ্যাপ ৫,০০০ বাইটের ছোট বা `</html>` নেই এমন ফাইল **নেয় না**
- নতুন ফাইল আগে আলাদা নামে নামে, পুরোটা ঠিকঠাক এলে তবেই বদলায়
