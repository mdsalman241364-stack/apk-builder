# NOVA — AIDE ভার্সন

এই জিপটা **AIDE-এর জন্য বানানো**। গ্র্যাডল নেই, `app/` ফোল্ডার নেই —
পুরোনো ধাঁচের ফ্ল্যাট স্ট্রাকচার, AIDE যেটা সরাসরি খুলতে পারে।

```
NOVA-AIDE/
├── AndroidManifest.xml
├── project.properties
├── src/com/salman/swadhin/*.java
├── assets/ui.html
└── res/
```

---

## ধাপ ০ — কিছুই করতে হবে না

**সার্ভার আগে থেকেই জোড়া দেওয়া আছে।** অ্যাপ ইনস্টল করে খুললেই চলবে —
API key বসাতে হবে না, সেটিংসে যেতে হবে না।

ভেতরে যা বসানো:

| | |
|---|---|
| সার্ভার | `https://nova.mdsalman0177598.workers.dev` |
| কোড | `salman` |
| key | সার্ভারে (Groq), অ্যাপে নেই |

টিমের কাউকে APK দিলে সে সেটিংসে গিয়ে শুধু **অ্যাকসেস কোড** বদলে
নিজেরটা বসাবে। বাকি সব একই থাকবে।

বদলাতে চাইলে `src/com/salman/swadhin/Cfg.java` এর উপরে
`RELAY_URL` আর `RELAY_CODE` লাইন দুটো আছে।

## ঐচ্ছিক — সরাসরি key দিয়ে চালানো

**নিজের ফোনে চালালে এই ধাপটা লাগবে না।** অ্যাপ খুলে সেটিংসে গিয়ে
Groq key বসিয়ে দিলেই হলো। ঝামেলা শেষ।

**বন্ধুদের APK দিতে চাইলে** শুধু একটা লাইন বদলাও, যাতে ওদের key দিতে না হয়।

AIDE-তে খোলো `src/com/salman/swadhin/Cfg.java`, উপরের দিকে এই লাইনটা পাবে:

```java
private static final String KEY = "";
```

কোটেশনের ভেতরে তোমার key বসাও:

```java
private static final String KEY = "gsk_তোমার_key_এখানে";
```

ব্যস। Termux লাগবে না, keygen লাগবে না, আর কিছু বদলাতে হবে না —
key দেখেই অ্যাপ বুঝে নেবে কোন প্রোভাইডার (`gsk_` → Groq, `AIza` → Gemini)।

> ⚠️ APK ডিকম্পাইল করলে key বেরিয়ে যায়। বিশ্বাসী বন্ধুদেরই দিও,
> আর ঐ key-তে কখনো billing চালু কোরো না।

## ধাপ ১ — AIDE-তে খোলা

জিপটা **`/sdcard/`-এ আনজিপ করো** (ইন্টারনাল স্টোরেজ, SD কার্ডে নয়)।
তারপর AIDE খুলে:

**Menu → Open file → `/sdcard/NOVA-AIDE/`** সিলেক্ট করো (ফোল্ডারটা, ভেতরের ফাইল নয়)

AIDE নিজেই `AndroidManifest.xml` দেখে বুঝে নেবে এটা Android প্রজেক্ট।

তারপর **Run (▶)**।

প্রথমবার বিল্ড হতে ২–৫ মিনিট লাগতে পারে। ধৈর্য ধরো।

## AIDE-তে যা যা আটকাতে পারে

**"No Android project found"**
→ ফোল্ডারটা সিলেক্ট করেছো তো, ভেতরের কোনো ফাইল নয়? আর `AndroidManifest.xml`
রুটে আছে কিনা দেখো।

**"assets folder not found" বা অ্যাপ সাদা স্ক্রিন**
→ `assets/ui.html` ঠিক জায়গায় আছে কিনা চেক করো। AIDE কখনো কখনো
আনজিপে খালি ফোল্ডার ফেলে দেয়।

**`R.string.xxx cannot be resolved`**
→ AIDE-তে **Menu → Project → Clean Project**, তারপর আবার Run।
এটা AIDE-র R.java রিজেনারেট না হওয়ার পুরোনো বাগ।

**`error: package android.provider does not exist`**
→ হবে না। MediaStore-এর API 29 কনস্ট্যান্টগুলো ইচ্ছে করেই স্ট্রিং লিটারেল
হিসেবে লেখা আছে, যাতে AIDE-র পুরোনো `android.jar`-এও কম্পাইল হয়।

**Java 8 এরর (lambda ইত্যাদি)**
→ হবে না। পুরো কোডে কোনো lambda, method reference, stream, বা
try-with-resources নেই। সব anonymous inner class — AIDE-র জন্য নিরাপদ।

**বিল্ড আউট অফ মেমোরি**
→ অন্য অ্যাপ বন্ধ করো। AIDE ফ্রি ভার্সনে বড় প্রজেক্টে হয়।

**"মডেল পাওয়া যায়নি" / key কাজ করছে না**
→ সেটিংস → AI ট্যাব → **Key টেস্ট করো** বাটন চাপো। এটা একটা ছোট রিকোয়েস্ট পাঠিয়ে
আসল কারণটা দেখাবে (ভুল key, ভুল মডেল, রেট লিমিট, নাকি API চালু নেই)।

Gemini key নিলে **console.cloud.google.com** এ গিয়ে
**Generative Language API** চালু আছে কিনা দেখো — AI Studio থেকে key নিলেও
মাঝে মাঝে এটা বন্ধ থাকে, তখন 403 আসে।

**run_code কাজ করছে না**
→ Android 4.4+ লাগে (`evaluateJavascript`)। minSdk 21, তাই সব ফোনেই চলার কথা।

**ডেক্স/মেথড লিমিট**
→ হবে না, কোনো লাইব্রেরি নেই। মোট ৩৪টা ক্লাস।

## কোডিং এজেন্ট

NOVA এখন শুধু কোড *দেখায়* না — তোমার আসল প্রজেক্ট ফোল্ডারে ঢুকে ফাইল পড়ে, খোঁজে, আর এডিট করে।

### চালু করা

১. Settings → AI ট্যাব → **কোডিং এজেন্ট মোড** সুইচ অন (ডিফল্টেই অন)।
২. নিচে **প্রজেক্ট ফোল্ডার** বক্সে তোমার কোডের পুরো পাথ দাও, যেমন `/sdcard/AppProjects/NOVA-AIDE`।
   ফোনে পাথ টাইপ করা ঝামেলা, তাই নিচে **চিপ** হিসেবে সম্ভাব্য প্রজেক্টগুলো নিজেই দেখাবে — চাপ দিলেই বসে যাবে।
৩. **সেট করো** চাপো। প্রথমবার স্টোরেজ পারমিশন চাইবে।

> **Android 11+**: শুধু সাধারণ পারমিশনে অন্যের ফোল্ডার পড়া যায় না। অ্যাপ নিজেই তোমাকে
> "সব ফাইলে অ্যাক্সেস" স্ক্রিনে পাঠাবে — সেখানে NOVA-কে অন করে ফিরে এসো।

প্রজেক্ট সেট না করলে NOVA আগের মতোই অ্যাপের নিজের ভেতরের ফোল্ডারে কাজ করে — কিছুই ভাঙে না।

### নতুন ১২টা টুল

| টুল | কী করে |
|---|---|
| `project_info` | প্যাকেজ, minSdk, বিল্ড সিস্টেম, ডিপেন্ডেন্সি — ফাইল পড়ে বের করে |
| `project_structure` | ফোল্ডার ট্রি (`bin/`, `build/`, `.git` বাদ দিয়ে) |
| `search_code` | পুরো প্রজেক্টে টেক্সট বা regex খোঁজে, `file:line` সহ |
| `find_symbol` | কোন ক্লাস/মেথড/`@+id` কোথায় ডিক্লেয়ার হয়েছে |
| `find_references` | একটা নাম আর কোথায় কোথায় ব্যবহার হয়েছে |
| `file_info` | সাইজ, লাইন সংখ্যা — ফাইল না খুলেই |
| `create_file` | নতুন ফাইল; আগে থেকে থাকলে **ফেল করে**, ওভাররাইট করে না |
| `edit_file` | হুবহু টেক্সট বদলায়। একাধিক জায়গায় মিললে **থেমে যায়** |
| `make_dir` | ফোল্ডার বানায় |
| `analyze_code` | ব্র্যাকেট ব্যালান্স, ডুপ্লিকেট import — গঠনগত যাচাই |
| `build_check` | পুরো প্রজেক্টের গঠন যাচাই |
| `read_agents` | `AGENTS.md`-এর নিয়ম পড়ে |

পুরোনো `read_file` এখন লাইন নম্বর দেয় আর লাইন-রেঞ্জ নেয়। `list_files` এখন যেকোনো সাব-ফোল্ডার দেখাতে পারে।

### দুইটা জিনিস ইচ্ছে করে কড়া রাখা হয়েছে

**`edit_file` ঝুঁকি নেয় না।** `old_text` যদি ফাইলে দুইবার থাকে, এডিট হয় না — এরর দেয়।
কারণ ভুল জায়গায় নিঃশব্দে এডিট হওয়ার চেয়ে এডিট না হওয়া ভালো। ইচ্ছে করে সব বদলাতে চাইলে `all=true`।

**পাথ গার্ড।** `../..`, বা প্রজেক্টের বাইরের absolute পাথ — দুইটাই সরাসরি রিফিউজ।
প্রজেক্ট ফোল্ডারের বাইরে NOVA কিছু ছুঁতে পারে না।

### যেটা এই অ্যাপ পারে না, আর সেটা লুকানো হয়নি

**ফোনের ভেতরে কোনো কম্পাইলার নেই।** তাই `build_check` কম্পাইল করে না — শুধু গঠন দেখে।
NOVA-কে সিস্টেম প্রম্পটেই বলে দেওয়া আছে সে যেন কখনো "বিল্ড সফল" না বলে,
আর `build_check`-এর আউটপুট নিজেই প্রথম লাইনে সীমাবদ্ধতাটা বলে দেয়।
**আসল বিল্ড AIDE-তেই করতে হবে।** এটা বাগ না, এটা সৎ থাকা।

### AGENTS.md

প্রজেক্টের রুটে `AGENTS.md` রাখলে NOVA প্রতি টার্নে সেটা পড়ে আর নিয়মগুলো মানে।
সাব-ফোল্ডারেও রাখা যায় — কাছেরটা পরে পড়া হয়, তাই সেটা বেশি জোর পায়।
Settings-এর **AGENTS.md বানাও** বাটনে চাপলে একটা ভালো ডিফল্ট তৈরি হয়
(আগের ফাইল থাকলে হাত দেয় না)।

## কোটা

**কোনটা ফ্রি সেটা আন্দাজ কোরো না — অ্যাপকে জিজ্ঞেস করো।**
সেটিংস → **Key টেস্ট করো**। মডেল না চললে অ্যাপ নিজেই তোমার key দিয়ে
সব মডেল একটা একটা করে বাজিয়ে দেখে, আর যেগুলো সত্যিই চলে সেগুলোর
চিপ দেখায় — ট্যাপ করলেই সিলেক্ট হয়ে যায়। এটাই একমাত্র নির্ভরযোগ্য উৎস,
কারণ ফ্রি লিস্ট প্রজেক্ট-ভেদে আলাদা আর প্রতি কয়েক মাসে বদলায়।

**মডেল লিস্ট যাচাই করা হয়েছে ১৯ আগস্ট ২০২৬** (Groq deprecation পেজ + Gemini
model lifecycle টেবিল)। যেগুলো বন্ধ হয়ে গেছে সেগুলো লিস্ট থেকে বাদ, আর
পুরোনো ফোনে সেভ থাকলে অ্যাপ নিজেই সেটা বাদ দিয়ে নতুনটা ধরে।

**Groq — এখানেই তোমার সমস্যা হচ্ছিল।** Groq `llama-3.3-70b-versatile` আর
`llama-3.1-8b-instant` **১৬ আগস্ট ২০২৬-এ বন্ধ করে দিয়েছে**, আর
`qwen3-32b` + `llama-4-scout` বন্ধ হয়েছে ১৭ জুলাই ২০২৬-এ। এগুলো দিলে এখন
এরর আসবেই। নতুন ডিফল্ট **`openai/gpt-oss-120b`**।
হালকা/দ্রুত চাইলে `openai/gpt-oss-20b`, আর টুল-কলিং সহ ভালো বিকল্প
`qwen/qwen3.6-27b`।

**Gemini** — নতুন ডিফল্ট **`gemini-3.5-flash`** (stable, রিটায়ারমেন্ট
২০২৭-এর আগে নয়)। আরও নতুন: `gemini-3.7-flash` (১৩ আগস্ট ২০২৬),
`gemini-3.6-flash`। সস্তা/দ্রুত: `gemini-3.5-flash-lite`,
`gemini-3.1-flash-lite`।
`gemini-2.0-flash` ২০২৬-এর জুনে বন্ধ, আর **২.৫ পরিবার ২০ অক্টোবর ২০২৬-এ
বন্ধ হবে** — তাই ওগুলোর উপর নির্ভর কোরো না।

দুটো টান আছে খেয়াল রেখো: কোটা **প্রতি প্রজেক্টে**, প্রতি key-তে নয় —
নতুন key বানালে কোটা বাড়বে না। আর প্রজেক্টে **billing চালু করলে ফ্রি টিয়ার
পুরো বন্ধ** হয়ে যায়; প্রোটোটাইপের জন্য billing-বিহীন আলাদা প্রজেক্ট রাখো।

### সার্ভার মোড — key অ্যাপে থাকবে না

টিমের জন্য সবচেয়ে ভালো পদ্ধতি। key থাকে সার্ভারে, অ্যাপে শুধু
একটা কোড। সার্ভারে যত ইচ্ছা key রাখা যায় — একটা শেষ হলে
নিজেই পরেরটা ধরে। কোটা শেষ হলে ১ ঘণ্টা পর আপনাআপনি সচল।

**Termux লাগে না** — ফোনের ব্রাউজারে ট্যাপ করে করেই হয়, ১০ মিনিট।
নিয়ম: **`server/README-server.md`**।

সেটিংসে প্রোভাইডার → **NOVA সার্ভার (কোড দিয়ে)** → ঠিকানা আর কোড বসাও,
মডেলের ঘর ফাঁকা রাখো।

### অ্যাপ থেকেই key যোগ

সেটিংসে **নতুন API key যোগ করো** ঘরটা আছে। Groq বা AI Studio থেকে key
নিয়ে ওখানে বসাও, সাথে অ্যাডমিন কোড — সার্ভার আগে বাজিয়ে দেখে সত্যিই
চলে কিনা, তারপর জমা রাখে। সবার অ্যাপ সাথে সাথেই সেটা পাবে।

Cloudflare এ যেতে হবে না। **এর জন্য KV আর `ADMIN` ভেরিয়েবল লাগবে।**

কোন key চলছে দেখতে ব্রাউজারে খোলো `<সার্ভার>/keys` — প্রতিটা key
সত্যিই বাজিয়ে দেখে সবুজ/লাল দেখায়।

### অটো-আপডেট (APK ছাড়া)

অ্যাপের চেহারা একটাই ফাইল — `assets/ui.html`। সেটা সার্ভারে পাঠালে
সবার অ্যাপ নিজেই নামিয়ে নেয়, নতুন APK দিতে হয় না।

ব্রাউজারে `<সার্ভার>/ui/upload` খুলে ফাইল বেছে দাও, তারপর Cloudflare এ
`UI_VERSION` এক বাড়াও। Termux লাগে না।

নিয়ম: **`server/README-update.md`**।

জাভা বদলালে (নতুন টুল, ক্যামেরা) নতুন APK লাগবেই — সেটা এভাবে যায় না।

### অটো-ফলব্যাক

সেটিংসের নিচে **ব্যাকআপ অ্যাকাউন্ট** সেকশন আছে। ওখানে দ্বিতীয় একটা
প্রোভাইডার + key দিয়ে রাখো (যেমন প্রধান Groq, ব্যাকআপ Gemini)।
প্রথমটায় কোটা শেষ (429) বা সার্ভার ডাউন (5xx) হলে অ্যাপ চুপচাপ
দ্বিতীয়টায় চলে যায় — চ্যাটে ছোট্ট একটা নোট দেখাবে, উত্তর থামবে না।

ব্যাকআপ থেকে আর ফলব্যাক হয় না, তাই দুটো ফেল করলে সাধারণ এরর আসবে।
পরের মেসেজে আবার প্রধান অ্যাকাউন্ট দিয়েই শুরু হবে।
